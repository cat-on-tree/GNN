\section*{Supplementary Results}

This Supplementary Information provides complete results under
degree-matched, standard relation-constrained, and inductive cold-start
evaluation. Tables~S1 and S2 report degree-matched evaluation, in which
the drug nodes in negative pairs were matched by degree to those in
positive pairs. Tables~S3 and S4 report results using standard
relation-constrained negative sampling.

Tables~S5 and S6 provide an additional inductive cold-start analysis
included in response to reviewer comments. In this setting, all test
drug nodes were entirely absent from the training graph and therefore
unseen during model training. For these nodes, the evaluated
structure-based GNNs lacked drug-specific neighborhood representations.
The cold-start analysis therefore focuses on semantic generalization
by the LLM-based models and is not treated as a primary claim of the
study.

Overall ranking and classification metrics are reported separately
from Top-\(K\) metrics to preserve readability. AUROC is reported only
for the balanced 1:1 setting, whereas AUPRC is reported only for the
imbalanced 1:4 and 1:9 settings. Non-applicable AUROC and AUPRC cells
are left blank. Values are shown as mean \(\pm\) standard deviation over
five evaluation runs.

Within each evaluation ratio, the best mean value in each metric is
shown in red boldface, and the second-best distinct mean value is shown
in boldface. For Top-\(K\) results, ranking is performed separately for
each ratio, cutoff, and metric. Rankings are based on mean values.

Llama3-8B is included as an additional open-source baseline.
Qwen3-235B-A22B is included as a model-scale reference rather than
a compute-matched baseline.

\section*{Notes on model comparisons}

Llama3-8B and Qwen3-8B are evaluated as open-source foundation-model
baselines. Qwen3-8B-SFT denotes the model after supervised fine-tuning
for KG-grounded drug-repurposing reasoning. Qwen3-8B-KTO denotes the
subsequent model aligned with Phase III clinical-development outcomes
using Kahneman--Tversky Optimization. Qwen3-235B-A22B is included only
as a large-scale open-source reference and is not considered a
compute-matched baseline.

The degree-matched evaluation controls drug-node degree and does not
assume that sampled negative drug--disease pairs represent clinical
failures. Phase III trial successes and failures are used as alignment
signals during KTO training and are conceptually distinct from the
negative pairs used in benchmark evaluation.

The inductive cold-start analysis is provided as a supplementary
response to reviewer interest and does not form part of the primary
clinical-outcome-alignment claim. Because the test drug nodes were
absent from the training graph, the evaluated structure-based GNNs
lacked drug-specific neighborhood representations for these nodes.
The cold-start tables therefore report only LLM-based models.
